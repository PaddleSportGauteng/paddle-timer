# PSG Timing — Dry Run Checklist (11 Sept 2026)

## Before you start
- [ ] Wipe test data on Render (Race Office → Delete this event, for every test meet)
- [ ] Hard refresh every device once (Ctrl+Shift+R) so they pick up the latest CSS/JS
- [ ] Second person on a tablet at the "finish line" who has NOT seen the system

## Setup (laptop, Race Office)
- [ ] Create meet: real name, Sprint, venue = where you are, lanes, 1 day
- [ ] Import the REAL entries sheet — check the flags it returns
- [ ] Confirm: names uppercase, one event per age/gender, club codes correct
- [ ] Conditions card appears; bearing shows venue default

## Race Sort
- [ ] Tick two small events, Combine — check the label and boat count
- [ ] Or click "Nothing to combine" — stepper ticks step 2

## Draw
- [ ] Generate all → every event goes orange "Drawn — check it"
- [ ] View one draw — lanes, names, columns all readable
- [ ] Confirm all → all green, stepper ticks step 3

## Race Program
- [ ] Set Day 1 start time, click Set times — races get times
- [ ] Auto-sequence — order makes sense (heats, then semis, then finals)
- [ ] Add gap (lunch) — it lands where you put it, times shift
- [ ] Export → Planning sheet PDF, Programme PDF, Draws Excel — open all three
- [ ] Finalise to Tower

## Starter page (phone at the start line)
- [ ] Open /start.html, race day mode ON
- [ ] Next race shows every lane with Here / Not here
- [ ] Mark one boat "Not here", leave one unchecked, rest "Here"
- [ ] Add a note ("lane 2 late, allowed to start")
- [ ] Start button shows the counts; press it
- [ ] Confirm on Tower: the "Not here" lane is already DNS, the unchecked one is untouched
- [ ] FALSE START drill: Recall → pick the offending lane → clock resets, race back on the start line, warning shows
- [ ] Recall the SAME lane again → system auto-DSQs it (ICF 10.2.11) and says so
- [ ] Try to give that DSQ'd lane a time on the Tower → it should refuse
- [ ] NO-FAULT drill: Recall → "nobody at fault" → no warning given to anyone
- [ ] Kill the starter phone's signal, start the same race from the Tower instead (fallback)
- [ ] Both press Start at once → no error, first press wins

## Tower (tablet person drives this)
- [ ] Race day toggle ON — setup nav collapses
- [ ] Start race 1, tap/space for 3–4 boats, Stop
- [ ] Type lane digits — each one assigns instantly, no Enter
- [ ] Delete one crossing, Edit one lane, Time-edit one result
- [ ] Mark one DNS, one DQ with reason
- [ ] Lock — race disappears from Tower, next race appears
- [ ] After LAST heat locks: semi appears with lanes filled automatically
- [ ] Deliberately Restart a race — clock resets to 00:00.00, confirm dialog appears
- [ ] Undo a tap, Unfinalise from Race Program, reorder with Up/Down, Finalise again

## Weigh (phone or second tablet)
- [ ] Finished race shows; DNS/DQ rows greyed "N/A"
- [ ] Log 3 weights, one below minimum → DQ flag
- [ ] Lock and confirm → race disappears, Results flips to Official

## Results
- [ ] Official pill, medal badges G/S/B, weights shown
- [ ] Conditions footer under each race (air temp, wind, head/tail)
- [ ] Reopen a race → goes back to Tower → fix → Lock again
- [ ] Prize giving view → grouped by distance/class/age/gender
- [ ] Excel, PDF, Print — all three, both views

## Live page (phone, on mobile data not wifi)
- [ ] Copy public live link from Race Office, open on phone
- [ ] NOW RACING shows with clock while a race runs
- [ ] Search own name — row highlights
- [ ] Results tab shows locked races; Official/Provisional correct

## Watch for

- Any screen that jumps/scrolls while typing
- Weather footer: if it shows nothing, Open-Meteo call from Render is blocked — tell me
- Any time that looks wrong (should be seconds, not minutes)
