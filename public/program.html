Race Program

No meet selected — pick or create one at the top-right first.

Need to draw or combine events first? Race Sort → Draw → Do that before setting times/finalising below.

1. Multi-day — assign events to days

If this meet runs over more than one day, set how many days and assign which distances run on which day. Leave at 1 day if everything runs on the same day.

2. Start times

Sets the anchor for race 1 — the rest space out by the interval below. Doesn't matter whether you do this before or after arranging the running order in section 2: reordering there always keeps race 1 pinned to whatever time you set here and re-flows everyone else to match, so nothing ever needs re-anchoring either way. New races created afterward (from combining, or heats auto-advancing to semis/finals) won't have a time until you run this again. Longer distances (2000m/5000m) needing more room than the standard gap? Set that race's own "min before next" in section 2 below — everything after it shifts to match automatically, wherever that race ends up if you reorder later.

3. Race Program

Every race for this meet, in order, once it's been drawn or combined above. This is where you fine-tune what's already been created — swap a lane, scratch someone, delete a race, set its time. Edit freely until you hit Finalise — only finalised races show up on the Tower. The PDF is generated fresh every time you click download — it always matches exactly what's below, never cached; if it ever looks different, it's because it was downloaded before a later change, not because it's out of sync.

Ordering: — a starting-point heuristic, not a full optimiser: it front-loads heats from multi-round events (so their semis/finals can start sooner) and mixes in straight finals so results keep coming. Use the ▲▼ buttons to nudge a race one place, or type a race number into the box and click → (or hit Enter) to jump straight there — whichever's moved always anchors back to race 1's original time, with everything else automatically shifting to match and renumbering correctly; no separate step needed. Semis/finals get their own time automatically once created (based on real rest gaps), so you won't see them here to reorder until their heats finish. Reordering here always keeps race 1 pinned to whatever start time is set in section 1 above, re-flowing everyone else to match — so it doesn't matter whether you sort before or after setting that.
Space keeper: for anything that needs a gap but isn't a race — moving a jetty between courses, lunch, tea. Give it a label and how many minutes it needs, pick where it goes, then use its own ▲▼/# controls afterward to fine-tune. Everything after it shifts automatically to match, wherever it ends up.
